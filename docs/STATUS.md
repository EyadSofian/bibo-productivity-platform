  لا stealth، لا تسجيل لمحتوى الكتابة، ولا التقاط كلمات مرور أو بيانات اعتماد.
- **F40 الأجهزة والتحكم لكل جهاز:** `READY FOR TEST`.

## ما اكتمل في F40

- مخزون أجهزة لكل شركة مع اسم الجهاز، النظام، إصدار العميل، الموظف، آخر نبضة، وحالة الاتصال.
- إيقاف/تشغيل المراقبة لكل جهاز مع عزل المستأجرين وتحديث متفائل في الواجهة.
- أرشفة واستعادة غير مدمرة؛ الاستعادة تبقي المراقبة متوقفة حتى التفعيل الصريح.
- العميل المكتبي يرسل hostname/OS/version ويواصل heartbeat حتى أثناء الإيقاف.
- كل قنوات الالتقاط تتوقف عند تعطيل الجهاز، والخلفية ترفض/تتجاهل الالتقاط المتأخر.
- واجهة RTL وترجمات اللغات الثماني وبيانات demo لموظفين، مع 11 اختبار واجهة مخصصًا.

**المتبقي قبل DONE:** تحقق يدوي على حزم macOS وWindows موصولة بخلفية حقيقية.

---

## ما اكتمل في نواة F41

- ملفات مراقبة مسماة، وراثة parent→child، وخصوصية، وتعيين على الشركة أو الموظف أو الجهاز.
- جدول مستقل لكل قناة (`applications`, `websites`, `screen`, `keystrokes`) بأيام ISO ووقت
  بدء/نهاية ومنطقة IANA، مع دعم النوافذ الليلية وDST.
- حل السياسة الفعلية للشركة ← الجهاز ← الموظف مع إظهار مصدر كل قيمة.
- REST CRUD وendpoint للسياسة المحلولة، مع تحقق UUID/JSON/timezone ومنع الدورات والتعيين
  خارج الشركة.
- تطبيق السياسة على عميل Rust؛ لوحة إدارة لإنشاء وتعديل وحذف الملفات ضمن التصميم الأصلي.
- keyboard tracking يبقى **عدد ضغطات مجمّع فقط** ولا يسجل النص المكتوب.

**المتبقي:** مجموعات directory بعد F46، cache محلي محمي، دفع تحديثات فوري،
واختبار end-to-end من لوحة الإدارة حتى عميل مُحزّم.
