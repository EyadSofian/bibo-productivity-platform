Live player harness — synthetic publisher

Stands in for the Windows agent and the SFU. It runs the real SyntheticTransport from the app source, so what you see below is a genuine MediaStream bound to a <video> element — not an image, and not a simulation of one.

What this proves: the rendering path, the stream binding, and teardown. What it does not prove: signalling, ICE, TURN, or anything about Windows capture.

Frame rate caveat. The draw loop is a timer, so it keeps running when the tab is hidden — but browsers throttle background timers to roughly 1 Hz. A hidden tab therefore shows about 1 fps no matter what fps is set to. That is the browser, not the player: keep this tab foregrounded when the rate matters.
